Lean 4.13.0 (2024-11-01)🔗

完整变更日志：https://github.com/leanprover/lean4/compare/v4.12.0...v4.13.0

语言特性、策略与元程序🔗

  • structure 命令

    • #5511 允许结构体父类型是类型同义词。

    • #5531 允许结构体字段的默认值是 noncomputable 的。

  • rfl 与 apply_rfl 策略

    • #3714、#3718 改进了 rfl 策略，并提供了更好的错误消息。

    • #3772 让 rfl 不再对封闭项使用内核 defeq。

    • #5329 为 Iff.refl 添加了 @[refl] 标记。（@Parcly-Taxel）

    • #5359 确保 rfl 策略会尝试 Iff.rfl。（@Parcly-Taxel）

  • unfold 策略

    • #4834 让 unfold 可以对局部定义执行 zeta-delta 规约，纳入了 Mathlib unfold_let 策略的功能。

  • omega 策略

    • #5382 修复了 #5315 中的伪错误。

    • #5523 支持 Int.toNat。

  • simp 策略

    • #5479 让 simp 能应用带高阶模式的规则。

  • induction 策略

    • #5494 修复了 induction 的 “pre-策略” 代码块，使其始终带有缩进，从而避免意外使用。

  • ac_nf 策略

    • #5524 添加了 ac_nf，作为 ac_rfl 的对应物，用于按结合律与交换律规范化表达式。并用 BitVec 表达式对其进行了测试。

  • bv_decide

    • #5211 让 extractLsb' 而不是 extractLsb 成为 bv_decide 识别的原语。（@alexkeizer）

    • #5365 添加了 bv_decide 诊断信息。

    • #5375 为 ofBool (a.getLsbD i) 和 ofBool a[i] 添加了 bv_decide 规范化规则。（@alexkeizer）

    • #5423 增强了 bv_decide 的重写规则。

    • #5433 在 API 层展示 bv_decide 的反例。

    • #5484 在 bv_decide 中处理带 Nat 自由变量的 BitVec.ofNat。

    • #5506、#5507 添加了 bv_normalize 规则。

    • #5568 泛化了 bv_normalize 流水线，以支持更一般的预处理过程。

    • #5573 让 bv_normalize 与当前的 BitVec 重写规则保持同步。

    • 清理工作：#5408、#5493、#5578

  • 精译改进

    • #5266 在 elab_as_elim 过程中保留过度应用参数的顺序。

    • #5510 泛化了 elab_as_elim，允许任意 motive 应用。

    • #5283、#5512 改进了具名参数抑制显式参数的方式。破坏性变更：某些此前可省略的显式参数现在可能需要显式写出 _。

    • #5376 修改了实例投影的 binder 信息：对于实例，如果其类型中某参数是实例隐式参数，那么投影中该参数也会变为隐式。

    • #5402 尽可能将宇宙元变量错误定位到 let 绑定和 fun binder 上；并让 “cannot synthesize metavariable” 错误优先于未解宇宙层级错误。

    • #5419 在可约性设置为 .reducible 时，不再在 match 表达式判别式中规约 ite。

    • #5474 让 autoparam 在失败时报告对应的参数/字段。

    • #5530 让带 hygienic 名称类型的自动实例名本身也保持 hygienic。

  • deriving 处理器

    • #5432 让 Repr 的 deriving 实例支持显式类型参数。

  • 函数式归纳

    • #5364 在上下文中加入更多等式，并进行更谨慎的清理。

  • 代码检查器

    • #5335 修复了未使用变量 linter 会对 match/策略组合误报的问题。

    • #5337 修复了未使用变量 linter 会对某些通配符模式误报的问题。

  • 其他修复

    • #4768 修复了当 .. 与下一行的 . 同时出现时的解析错误。

  • 元编程

    • #3090 在 Meta.evalExpr 中处理层级参数。（@eric-wieser）

    • #5401 为 Inhabited (TacticM α) 添加实例。（@alexkeizer）

    • #5412 出于调试目的公开 Kernel.check。

Lake🔗

  • Reservoir 构建缓存。Lake 现在会在构建前尝试从 Reservoir 获取该包的预构建副本。此功能仅对 leanprover 或 leanprover-community 组织中、且版本已被 Reservoir 索引的包启用。用户可以通过在 CLI 上传入 --no-cache，或将环境变量 LAKE_NO_CACHE 设为 true，强制 Lake 从源码构建包。#5486、#5572、#5583、#5600、#5641、#5642。

  • #5504 让 lake new 和 lake init 默认生成 TOML 配置。

  • #5878 修复了一个严重问题：当 Lake 试图清理以错误名称声明的依赖时，可能会删除路径依赖。

  • 破坏性变更

    • #5641 在包内构建某个目标时，Lake 将不再构建该包依赖项的包级额外目标依赖。从技术上说，一个包的 extraDep facet 不再传递性地构建其依赖项的 extraDep facet（其中包括它们的 extraDepTargets）。
